# Contributing to PyPetiGame

## Golden rule: never commit directly to `master`

All changes — including docs-only ones — go through a pull request:

1. Create a branch from `master`: `openclaw/<short-name>`
2. Commit + push the branch
3. Open a PR (draft is fine) and let CI run on the local runner
4. Merge only after review + green CI

Direct pushes to `master` bypass review and CI. Don't do it.
