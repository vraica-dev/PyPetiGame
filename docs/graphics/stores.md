# Stores — free vs paid (verified 2026-11-06)

## FREE

1. **Kenney.nl — https://kenney.nl/assets** — 100+ packs (Food, Animals, UI, Backgrounds, fonts, audio), PNG+SVG, CC0 (https://kenney.nl/license). Best free fit: Food Pack, Animal Pack, UI Pack, Background Elements. Free, donations optional.
2. **OpenGameArt.org — https://opengameart.org/** — community sprites/BGs/UI/fonts. Mixed per-asset license — filter CC0/CC-BY, credit CC-BY. Only free source likely with actual cat sprites + fish/milk powerups. Free.
3. **itch.io free — https://itch.io/game-assets/free** — indie cat sprites, snack icons, cartoon UI, parallax BGs. Per-page license (many CC0/CC-BY). Tags: `cats`, `food`, `2d`, `gui` (avoid `pixel-art`). $0.
4. **GameArt2D Freebies — https://www.gameart2d.com/freebies.html** — curated cartoon (Cute Cat, Candy World, Forest 1920x1080). Freebies = commercial with credit; paid = no credit. Re-check https://www.gameart2d.com/license-2.html before ship.
5. **CraftPix Freebies — https://craftpix.net/freebies/** — cartoon characters, food/icons, match-3 candy, UI kits, 1920x1080 BGs. Custom free license (usually credit + commercial OK, some personal-only — check badge). Account required.
6. **Fonts + icons (free)** — Google Fonts OFL (Baloo 2, Fredoka, Nunito): https://fonts.google.com/ + https://fonts.google.com/specimen/Baloo+2 ; Font Squirrel: https://www.fontsquirrel.com/ ; game-icons.net CC-BY 3.0 (4000+ food/powerup icons): https://game-icons.net/
7. SFX-safe bonus: OpenGameArt audio (CC0/CC-BY filter), Freesound.org (avoid NC), Kenney Audio: https://kenney.nl/assets?q=audio

## PAID ($2–$100)

7. **itch.io paid — https://itch.io/game-assets** (~$2–$25/pack) — cheapest coherent cat + treats from one artist.
8. **GameDev Market — https://www.gamedevmarket.net/category/2d/** (~$5–$50, bundles $20–$100) — HD cartoon cats, food icons, 1920x1080 BGs.
9. **Unity Asset Store 2D — https://assetstore.unity.com/2d** ($0–$80) — PNGs usable outside Unity, good 1080p previews.
10. **Envato GraphicRiver — https://graphicriver.net/category/game-assets** (~$8–$40) — polished UI/BGs.
11. **Fab / ArtStation — https://www.fab.com/ + https://www.artstation.com/marketplace/game-assets/2d** (~$5–$60) — stylized 2D backup.

Uncertainty: marketplace pages are JS-heavy; prices are ranges to re-check on the page before buying.
